Android Java Distributed Systems

Distributed Food Ordering System

A full-stack ordering platform combining a native Android client with a Java TCP backend and SQLite persistence. Designed to showcase real distributed-systems thinking — not just a mobile UI — supporting both customer and partner/manager workflows.

Stack: Java 11, Android SDK, TCP Sockets, JSON Protocol, Room/SQLite, Material Design 3, Gradle (Kotlin DSL), JUnit 5

  • Built around raw TCP sockets with a custom JSON protocol, explicit handshake flow, and reconnect handling.
  • Layered architecture (UI → Service → Repository → Protocol) keeps networking, business logic, and presentation clearly separated.
  • Thread-safe basket and socket handling, plus server-side validation for prices, stock, and one-time access-code login.
  • End-to-end: customer browsing/ordering flows and partner portal for inventory and store management.

R EDA Classification

Instagram Reach EDA & Logistic Regression

Exploratory data analysis and interpretable binary classification on an Instagram engagement dataset. Moves from data inspection and feature engineering to logistic regression modelling, with emphasis on readable statistical reasoning and honest evaluation.

Stack: R, R Markdown, exploratory data analysis, logistic regression

Aegean Blue Houses — Website & Living Atlas

⭐ Featured

The bilingual (English/Greek) website of Aegean Blue Houses, four holiday houses above Mandrakia on Milos. I designed and built it as an editorial, "volcanic quiet" experience: Milos stone and plaster textures, scroll-led section arrivals, a full-screen stone menu and a single site-wide footer, delivered on WordPress through custom must-use plugins with versioned, cache-safe releases.

Stack: WordPress (Elementor, WPML, custom PHP mu-plugins), HTML, CSS, JavaScript, Three.js / GLSL shaders, Vite, Playwright, Node.js deploy tooling (FTPS, rollback, LiteSpeed cache purge)

Living Atlas: a Three.js map of Milos and Kimolos built from real elevation data. On arrival the empty frame fills with water from several springs (depth colour, refraction, caustics, foam), the islands rise through the surface and dry from the summits down, and the relief carves itself finer wherever the visitor moves the cursor.
